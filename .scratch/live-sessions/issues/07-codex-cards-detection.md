# 07: Codex 卡片（程序偵測與對應）

**What to build:** 頁面也出現終端機裡還開著的 Codex CLI session。Codex 沒有 session 登記資料夾，所以從系統裡正在跑的 `codex` 互動程序反推：只算有終端機的互動程序，排除 app-server 常駐程序、VS Code 擴充套件的程序與桌面版。程序對應到對話的規則：啟動參數帶有對話 id 就直接用；否則取同一資料夾中最近更新的對話。對話資料取自 Codex 的本機狀態資料庫（WAL 模式，必須以一般唯讀方式開啟才看得到最新資料，尊重 `CODEX_DIR` 覆寫），只收來源為使用者的對話，不收子 agent。卡片顯示「Codex」標示、名稱、資料夾、工作中或閒置（最後一個回合開始之後沒有完成或中止就是工作中），並與 Claude Code 的卡片一起排序。
