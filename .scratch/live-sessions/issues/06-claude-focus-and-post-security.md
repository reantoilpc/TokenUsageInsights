# 06: 點卡片跳到 Ghostty 分頁（Claude Code）與 POST 安全防護

**What to build:** 點一張 Claude Code 卡片，就跳到那個 session 所在的 Ghostty 分頁。比對規則：工作資料夾相同，且分頁標題以 session 名稱結尾（沒有名稱就只比資料夾）；多個符合就跳到第一個；一個都找不到就在頁面顯示「找不到這個 session 的分頁」，不自動開新分頁。跳轉用 POST 請求，只接受來自看板自己頁面的 JSON 請求，請求內容只有 agent 與 id，資料夾與名稱由伺服器依 id 自己查。

**Blocked by:** 02

**Status:** ready-for-agent

**Spec:** ../spec.md

- [ ] 請求來源等於伺服器自己的位址、且內容類型為 JSON 才處理；缺少來源、來源不符、內容類型不對一律拒絕，且假的 `osascript` 沒有收到任何呼叫（測試）
- [ ] 請求的 id 必須是目前清單上已知的 session；未知或格式錯誤的 id 拒絕（測試）
- [ ] 請求內帶了資料夾或指令文字時，一律忽略或拒絕，不影響實際執行的內容（測試）
- [ ] 假的 `osascript` 收到的比對條件正確：資料夾、標題結尾名稱；無名稱時只有資料夾（測試）
- [ ] 找不到分頁時回傳「找不到」，頁面顯示「找不到這個 session 的分頁」，且沒有新開分頁的呼叫（測試）
- [ ] 非 macOS 或 Ghostty 未執行時，回傳明確的不支援或找不到訊息，不報內部錯誤（測試，以會失敗的假 `osascript` 模擬）
- [ ] 點擊卡片標題即觸發跳轉
- [ ] 通過提交前檢查（同 01）
