# 19: 剛壓縮時，context 不要還顯示壓縮前的大小

**What to build:** Claude Code 的對話壓縮後、下一次回覆之前，卡片的 context 還是顯示壓縮前的大小（例如 341K），看起來像快要被壓縮，其實剛壓縮完。改為副標寫「context 剛壓縮」、不寫數字，滑鼠停留時說明「壓縮前 341K，下一次回覆後顯示新的大小」；下一次回覆後恢復顯示數字。

壓縮分界雖然記有壓縮後的 token 數，但本機 46 次壓縮的資料顯示它比下一次實際送出的少 5.6 萬～7.8 萬，所以不拿來顯示（使用者 2026-10-29 選定）。細節見規格的「實作決策 → 卡片內容」。
