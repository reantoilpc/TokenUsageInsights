# 10: Codex 跳轉與同資料夾多個程序的區分

**What to build:** 點 Codex 卡片跳到對應的 Ghostty 分頁。比對規則：工作資料夾相同，且分頁標題開頭是對話名稱（Codex 的標題格式為「對話名稱 | 資料夾名稱」）。同一資料夾開了兩個以上 Codex、而且沒有 id 可用時，改用 Ghostty 各分頁的標題去比對對話名稱，讓每個程序對應到正確的對話與分頁，不再只顯示一張卡片。找不到分頁的處理與 Claude Code 相同。

**Blocked by:** 06, 07

**Status:** ready-for-agent

**Spec:** ../spec.md

- [x] 假的 `osascript` 收到的 Codex 比對條件正確：資料夾相同、標題開頭為對話名稱（測試）
- [x] 多個符合取第一個；沒有符合時回傳「找不到」且不開新分頁（測試）
- [x] 同資料夾兩個 Codex 程序、沒有 id 時，依分頁標題各自對應到正確的對話，出現兩張卡片（測試，以假的分頁標題清單劇本）
- [x] 標題比對要求名稱後面接「 | 」：「fix」不會對到「fix login」；沒有 id 的程序只對應終端機版（codex-tui）的對話（測試）
- [x] 標題無法區分時，保守地只顯示一張卡片，不顯示錯誤對應
- [x] 沿用工單 06 的 POST 安全規則；Codex 的請求同樣只帶 agent 與 id（測試）
- [x] 通過提交前檢查（同 01）
