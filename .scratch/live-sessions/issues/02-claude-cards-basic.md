# 02: Claude Code 卡片（基本）

**What to build:** 頁面出現所有還開著的 Claude Code session，一個 session 一張卡片。每張卡片顯示名稱（沒有名稱就用資料夾名稱）、資料夾名稱、「Claude Code」標示，以及狀態：工作中或閒置。清單來自 Claude Code 自己維護的 session 登記資料夾（尊重 `CLAUDE_DIR` 覆寫），每一筆還要確認程序仍然活著。卡片依狀態排序，並依視窗寬度自動排成多欄。

**Blocked by:** 01

**Status:** ready-for-agent

**Spec:** ../spec.md

- [x] 登記檔狀態為 busy 或 shell 顯示「工作中」，idle 顯示「閒置」（測試）
- [x] 登記檔存在但程序已死的 session 不出現在清單（測試）
- [x] 登記資料夾內的 `.key` 檔從不被開啟或讀取；測試放一個內含哨兵字串的 `.key`，斷言回應中沒有該字串
- [x] 沒有名稱的 session 以資料夾名稱當卡片標題（測試）
- [x] 排序：工作中在前、閒置在後；同狀態內最近更新的在前（測試）
- [x] 不同狀態用不同顏色；卡片依寬度多欄排列；沿用既有深淺主題
- [x] 整合測試以假的登記檔與可控的存活判斷執行，不在正式程式碼加測試專用開關
- [x] 通過提交前檢查（同 01）
