# 01: 空頁面骨架

**What to build:** 在首頁頂部加一個「進行中」連結，進到新的獨立頁面。沒有任何 session 時，頁面顯示「目前沒有進行中的 session」。頁面在可見時每 3 秒向後端取一次資料，切到別的瀏覽器分頁就暫停。後端提供即時清單的 API，目前回傳兩份空清單（進行中、最近結束）。同時把網站預設改成只接受本機連線，並建立這個功能專用的整合測試骨架：啟動真正的程式、指到暫存資料夾，並把假的 `ps`、`lsof`、`osascript` 放在 PATH 最前面，這些假指令能依劇本回答，也會記錄收到的參數。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Spec:** ../spec.md
